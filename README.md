# YourWorld — Creative Stories, Sharing & PDF Tools

YourWorld is a web workspace for creating and sharing stories, organizing files, making creative projects, and working with PDFs.

**Try it:** [worldbyyou.com](https://worldbyyou.com/)

> This public repository is a project overview for visitors and reviewers. It contains no application source code. YourWorld’s production code is maintained privately.

## What you can do

### Create and share stories
- Write and format multi-page stories on a visual canvas.
- Add images and files, personalize pages, and preview shared content.
- Share with generated or custom codes and choose whether recipients can view or edit.
- Present stories as slideshows and export or download content where supported.

### Work with PDFs
- Open PDFs in the browser and make visual edits.
- Add text, images, signatures, highlights, drawings, and shapes.
- Replace detected text and adjust the replacement’s font, size, color, background, alignment, and text styling.
- Use OCR-assisted text detection on scanned pages, then review edits in the page preview before exporting.
- Move and rotate added or replacement text, with undo and redo for supported edits.

PDF appearance can depend on the source document, available font information, and whether text is selectable or scanned. Review the exported PDF for layout and font fidelity.

### Make creative projects in Studio
- Build and edit visual projects with media, text, templates, and effects.
- Preview and export finished work.
- Use Studio alongside YourWorld’s story and sharing tools.

### Organize and share files
- Keep uploaded content in the Private Vault.
- Share selected files or pages through Quick Share and access codes.
- Drag files into supported upload areas for a faster upload flow.
- Preview shared content before opening or downloading it.

### Usability and reliability
- Responsive layouts for desktop and mobile.
- Editing controls and previews designed to make changes easier to inspect.
- Ongoing fixes to editing, upload, sharing, and export workflows.

## A typical workflow

**Create or upload → edit and preview → organize or personalize → share with the right access → view, present, or export**

## About this repository

This repository is intentionally a README-only public showcase. It does not provide the source code or a self-hostable package. To use YourWorld, visit the live site.

The private application integrates a web backend and frontend with storage and creative services. Implementation details and credentials are kept out of this public overview.
